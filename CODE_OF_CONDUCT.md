# Code of conduct

Be decent. Specifically:

- Assume the other person is acting in good faith and knows something you do not.
- Critique the code, the design and the documentation — not the person.
- No harassment, no discrimination, no personal attacks, no publishing someone's private information.
- Maintainers may edit, lock or close anything that makes the project worse to be around, and may ban
  repeat offenders.

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its standard; where this short text and that document disagree, the Covenant applies.

Report problems to the maintainer listed in the repository profile. Reports are handled privately.
