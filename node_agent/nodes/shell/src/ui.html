Four switches, one per kind of thing this node does: READ (files, searches, previews), WRITE (files, publishing), EXEC (commands and the sessions they become, local nodes) and EXEC_CUSTOM (the commands saved below). A group that is off refuses every capability it covers before it runs, by name: shell.exec is disabled by the user for node "agent". The node keeps one cap + callers rule per capability, in a file per tenant under the node-agent home, so a restart keeps them without the history node being involved. When the group holding a management capability (permissions, custom-commands) is off, other callers are refused, but webui can always reach the page to turn it back on.
