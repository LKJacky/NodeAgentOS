What's NodeAgent

一个你自己运行的 agent：记得你、能做事，也能按你的时间表主动醒来。

你可以用它做什么

日常怎么用

  • 左边对话，右边功能页；历史一直保留。

和它说话

在左边的对话框里直接说。它保留完整历史，重启后还能接着聊。

记住你

把偏好、项目背景和重要事件写进 notes，下次不用从头解释。

安排事情

用 todo 记今天要做什么，用 timer 设提醒，也可以让它定时主动执行任务。

动手和查资料

让它运行命令、读写文件、搜索网页；能不能做、做到哪一步，由你在 system 页面里控制。

连接你的电脑

在另一台电脑上启动一个 shell Node，它就能在那台电脑上读写文件、执行命令。

连接你的电脑

以连接外部电脑为例。先在目标电脑上启动 shell，之后 agent 就能在那台电脑上读写文件和执行命令。这是当前用户的 join token，只发给可信的电脑。直接用总线原始 token 加入的节点不会出现在这个用户的 UI 里。

总线地址 {{busUrl}}
加入 token {{token}}

This bus is listening on loopback.

1. 设置连接并启动 shell

在要接入的电脑上运行：

env \
  NODE_AGENT_BUS_URL="{{busUrl}}" \
  NODE_AGENT_TOKEN="{{token}}" \
  npx @node-agent/shell --name computer

--name computer是它在总线上的名字；接入多台电脑时给每台一个不同的名字。启动后 agent 会看到这些能力：computer.read computer.exec

验证：回到 Web UI，节点列表里应出现computer；再让 agent 调用list_nodes computer.exec computer.read，能拿到结果就说明接好了。

这一页只介绍怎么用和怎么接入节点：页面里的复制按钮只写剪贴板，不执行命令。
